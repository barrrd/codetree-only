## ⚠️ 구현 시 주의해야 할 핵심 포인트

### 1) 현재 방향 벡터를 기준으로 직진 → 좌회전 → 우회전 → 후진 순서 생성

1단계에서는 현재 고래가 바라보는 방향을 기준으로 다음 순서대로 인접한 미방문 바다를 확인해야 합니다.

```text
1. 직진
2. 좌회전
3. 우회전
4. 180도 회전
```

현재 방향을 `(cdr, cdc)`라는 방향 벡터로 관리하면, 별도로 방향 번호를 다시 찾지 않고 회전 방향을 바로 계산할 수 있습니다.

```python
check_lst = [
    (cdr, cdc),       # 직진
    (-cdc, cdr),      # 좌회전
    (cdc, -cdr),      # 우회전
    (-cdr, -cdc)      # 180도 회전
]
```

방향 벡터 `(dr, dc)`에 대한 회전 관계는 다음과 같습니다.

```text
직진      : ( dr,  dc)
좌회전    : (-dc,  dr)
우회전    : ( dc, -dr)
180도     : (-dr, -dc)
```

* **오류 예시:** `상, 하, 좌, 우`처럼 회전 순서가 아닌 방향 배열에서 `(d - 1) % 4`, `(d + 1) % 4`를 사용하면 실제 좌·우회전 방향과 일치하지 않을 수 있습니다.
* **핵심:** 현재 방향 자체를 `(cdr, cdc)`로 저장하고 방향 벡터를 직접 회전시킵니다.
* **➡️ 해결 방법:**

  * `check_lst`를 `직진 → 좌 → 우 → 뒤` 순서로 생성합니다.
  * 앞에서부터 미방문 바다인지 확인합니다.
  * 이동 가능한 첫 번째 칸을 찾으면 즉시 이동하고 탐색을 종료합니다.
  * 이동한 방향 `(dr, dc)`를 새로운 `cdr, cdc`로 갱신합니다.

```python
for dr, dc in check_lst:
    nr, nc = sr + dr, sc + dc

    if not (0 <= nr < N and 0 <= nc < N):
        continue
    if marr[nr][nc] > 0:
        continue

    marr[nr][nc] = 2
    sr, sc = nr, nc
    cdr, cdc = dr, dc
    turn -= 1
    break
```

### 2) 2단계의 목적지 선택과 이동 경로 선택은 서로 다른 우선순위

2단계에서는 우선순위가 두 종류 존재하므로 이를 섞어서 처리하면 안 됩니다.

먼저 **목적지를 선택할 때**는 다음 순서를 따릅니다.

```text
1. 현재 위치에서 가장 가까운 미방문 바다
2. 거리가 같으면 행이 작은 칸
3. 행도 같으면 열이 작은 칸
```

반면 목적지를 결정한 뒤 **최단 경로를 선택할 때**는 다음 우선순위를 사용합니다.

```text
좌 → 하 → 우 → 상
```

따라서 현재 구현에서는 2단계를 두 번의 BFS로 분리했습니다.

---

#### 2-1) 첫 번째 BFS: 가장 가까운 미방문 바다 찾기

현재 위치 `(sr, sc)`에서 BFS를 수행하면서 가장 가까운 `0`을 찾습니다.

이때 현재 구현에서 바다 상태는 다음과 같습니다.

```text
marr
  0 : 아직 방문하지 않은 바다
  1 : 암초
  2 : 이미 방문한 바다
```

탐색 중:

```text
1
→ 암초이므로 이동 불가능

2
→ 이미 방문한 바다이므로 통과 가능

0
→ 아직 방문하지 않은 바다이므로 목적지 후보
```

가장 가까운 미방문 바다의 거리를 `best_dist`로 관리합니다.

```python
best_dist = float("INF")
cand = []
```

새로운 미방문 바다를 발견하면:

```python
if ndist < best_dist:
    best_dist = ndist
    cand = [(nr, nc)]

elif ndist == best_dist:
    cand.append((nr, nc))
```

와 같이 처리합니다.

* **오류 예시:** 최소 거리의 미방문 바다를 처음 발견했다고 즉시 BFS를 종료하면, 같은 거리의 다른 후보를 확인할 수 없습니다.
* **핵심:** `best_dist`와 같은 거리의 후보까지 모두 수집해야 합니다.
* **➡️ 해결 방법:**

  * 처음 발견한 최소 거리를 `best_dist`에 저장합니다.
  * 같은 거리의 미방문 바다는 모두 `cand`에 추가합니다.
  * 이미 `cdist >= best_dist`라면 그 위치에서 더 이동하면 최소 거리보다 멀어지므로 추가 탐색하지 않습니다.

```python
if cdist >= best_dist:
    continue
```

최소 거리 후보를 모두 찾은 이후에는 행과 열을 기준으로 정렬합니다.

```python
cand.sort(key=lambda x: (x[0], x[1]))
tr, tc = cand[0]
```

따라서 최종 목적지는

```text
최소 거리 → 최소 행 → 최소 열
```

순서로 결정됩니다.

### 3) 목적지가 결정된 후 다시 BFS하여 `좌 → 하 → 우 → 상` 우선순위의 최단 경로 선택

목적지 `(tr, tc)`를 찾았다고 바로 해당 위치로 이동시키면 안 됩니다.

문제에서는 목적지까지 최단 거리로 이동하되, 최단 경로가 여러 개라면 **각 이동에서 좌 → 하 → 우 → 상 우선순위**를 적용해야 합니다.

따라서 현재 위치에서 두 번째 BFS를 수행합니다.

```python
dist = [[-1] * N for _ in range(N)]
dist[sr][sc] = 0

q = deque([(sr, sc)])
```

BFS 탐색 방향 자체를 문제의 우선순위와 동일하게 유지합니다.

```python
for dr, dc in [
    (0, -1),   # 좌
    (1, 0),    # 하
    (0, 1),    # 우
    (-1, 0)    # 상
]:
```

BFS는 같은 이동 횟수의 칸을 순서대로 탐색하므로, 목적지를 처음 발견한 경로는 최단 경로이며 동일한 길이의 경로 중에서는 `좌 → 하 → 우 → 상` 순서가 우선적으로 반영됩니다.

또한 `dist`의 `-1`을 BFS에서 아직 방문하지 않은 상태로 사용합니다.

```text
-1 : BFS에서 아직 방문하지 않은 칸
 0 : 시작 위치
 1 : 시작 위치에서 1칸
 2 : 시작 위치에서 2칸
 ...
```

이미 방문한 칸은 BFS 특성상 처음 기록된 값이 최단 거리이므로 다시 갱신하지 않습니다.

```python
if dist[nr][nc] != -1:
    continue

dist[nr][nc] = dist[cr][cc] + 1
q.append((nr, nc))
```

* **오류 예시:** `dist[nr][nc]`가 이미 `2`인데 이후 거리 `3`으로 다시 접근했다고 값을 갱신하면 최단거리 정보가 깨집니다.
* **핵심:** BFS에서 어떤 칸을 처음 방문한 순간의 거리가 해당 칸까지의 최단거리입니다.
* **➡️ 해결 방법:** `dist[nr][nc] != -1`이면 해당 칸은 다시 큐에 넣지 않습니다.

목적지를 처음 발견한 순간의 `(dr, dc)`는 목적지로 들어간 **마지막 이동 방향**이므로 이를 바로 현재 방향으로 저장할 수 있습니다.

```python
if (nr, nc) == (tr, tc):
    cdr, cdc = dr, dc
    sr, sc = nr, nc
    found = True
```

문제에서 요구하는

```text
도착 후 바라보는 방향
= 목적지로 마지막에 이동한 방향
```

을 별도로 경로 전체를 복원하지 않고 처리할 수 있습니다.

### 4) 실제 바다 방문 여부와 BFS 내부 방문 여부를 분리하여 관리

이 문제에서는 두 종류의 `visited` 개념을 구분해야 합니다.

```text
marr
  0 : 아직 고래가 방문하지 않은 바다
  1 : 암초
  2 : 이미 고래가 방문한 바다
```

`marr`는 전체 시뮬레이션 동안 유지되는 실제 방문 상태입니다.

반면 `v`와 `dist`는 한 번의 BFS 안에서 중복 탐색을 방지하기 위해 사용하는 임시 방문 정보입니다.

```text
v[r][c]
  False : 이번 BFS에서 아직 탐색하지 않음
  True  : 이번 BFS에서 이미 탐색함

dist[r][c]
  -1 : 이번 BFS에서 아직 탐색하지 않음
  0 이상 : 시작점으로부터의 최단 거리
```

* **오류 예시:** `marr == 2`라는 이유로 BFS에서 방문 체크를 하지 않으면, 이미 방문한 바다 사이를 계속 반복해서 큐에 넣을 수 있습니다.
* **핵심:** `marr`의 방문 여부와 BFS의 방문 여부는 목적이 다릅니다.
* **➡️ 해결 방법:**

  * `marr`는 고래의 실제 탐험 상태를 관리합니다.
  * 첫 번째 BFS에서는 별도의 `v` 배열을 사용합니다.
  * 두 번째 BFS에서는 `dist == -1` 여부를 BFS 방문 체크로 사용합니다.

### 5) 남아 있는 미방문 바다의 개수를 `turn`으로 관리

모든 바다를 방문했는지 매번 전체 `N × N` 배열을 다시 탐색하지 않고, 남아 있는 미방문 바다의 개수를 `turn`으로 관리했습니다.

초기 전체 칸은 `N × N`개이고,

* 암초는 방문 대상이 아니며
* 시작 위치는 이미 방문한 상태

이므로 다음과 같이 계산합니다.

```python
turn = N * N - 1

for m in marr:
    turn -= sum(m)
```

입력 상태에서는 암초가 `1`, 바다가 `0`이므로 `sum(m)`은 해당 행의 암초 개수가 됩니다.

따라서 최종적으로:

```text
turn
= 전체 칸 수
- 암초 개수
- 시작 위치 1칸
```

즉 앞으로 방문해야 할 바다 칸의 개수가 됩니다.

새로운 바다를 방문할 때마다:

```python
turn -= 1
```

을 수행하고,

```python
while turn > 0:
```

인 동안 시뮬레이션을 반복합니다.

시작 위치는 처음부터 방문 처리합니다.

```python
marr[sr][sc] = 2
```

## 📌 전체 구현 흐름

```text
초기화
├─ 시작 위치 (sr, sc)
├─ 현재 방향 (cdr, cdc)
├─ 시작 위치 방문 처리
└─ 남은 미방문 바다 수 turn 계산

반복
│
├─ Step 1. 인접 탐험
│   ├─ 직진
│   ├─ 좌회전
│   ├─ 우회전
│   └─ 180도
│
│   이동 가능
│   └─ 한 칸 이동
│      ├─ marr = 2
│      ├─ 방향 갱신
│      └─ turn -= 1
│
└─ 인접 미방문 바다가 없음
    │
    └─ Step 2. 가장 가까운 바다로 이동
        │
        ├─ BFS 1
        │   ├─ 가장 가까운 미방문 바다 탐색
        │   ├─ 최소 거리 후보 모두 저장
        │   └─ 행 → 열 순서로 목적지 결정
        │
        ├─ BFS 2
        │   ├─ 현재 위치에서 목적지까지 최단 경로 탐색
        │   └─ 좌 → 하 → 우 → 상 우선순위 적용
        │
        └─ 목적지 도착
            ├─ 현재 위치 갱신
            ├─ 마지막 이동 방향 갱신
            ├─ marr = 2
            └─ turn -= 1

turn == 0
→ 모든 바다 방문 완료
→ 종료
```

## 🗂️ 주요 변수

```text
marr[r][c]
  0 : 아직 방문하지 않은 바다
  1 : 암초
  2 : 이미 방문한 바다

sr, sc
  : 현재 아기 고래의 위치

cdr, cdc
  : 현재 바라보고 있는 방향 벡터

turn
  : 아직 방문하지 않은 바다 칸의 개수

best_dist
  : Step 2에서 발견한 가장 가까운 미방문 바다까지의 거리

cand
  : best_dist와 동일한 거리에 존재하는 목적지 후보

tr, tc
  : 거리 → 행 → 열 우선순위로 결정된 최종 목적지

v
  : Step 2의 첫 번째 BFS에서 사용하는 방문 배열

dist
  : Step 2의 두 번째 BFS에서 사용하는 최단거리 및 방문 배열
```
